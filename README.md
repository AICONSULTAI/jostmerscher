# jostmerscher.de

Website von Jost Merscher: Bilder, Objekte, Collagen und Romane.
Statische Seite (HTML, CSS, JavaScript), veröffentlicht über GitHub Pages unter www.jostmerscher.de.

- `index.html`: die Seite
- `assets/works/`: Werkfotos je in drei Größen (`-800`, `-1200`, groß)
- `assets/books/`: Buchcover (© Ganymed Edition)
- `tools/make_placeholders.py`: erzeugt die Platzhalterbilder des Entwurfs

Schriften: Source Serif 4 und Libre Franklin (SIL Open Font License), lokal eingebunden.
